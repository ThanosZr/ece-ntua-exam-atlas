# ΣΗΜΜΥ ΕΜΠ — exam order pattern

Interactive Sankey/alluvial + bump chart comparing the relative exam order
of 19 recurring courses in the official February 2024, 2025 and 2026 schedules.

## GitHub Pages
1. Put `index.html` in the repository root.
2. Settings → Pages.
3. Deploy from branch → `main` / root.
